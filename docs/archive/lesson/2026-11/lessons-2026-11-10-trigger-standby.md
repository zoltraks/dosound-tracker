# Session Findings

Durable lessons recorded when a session ends.

Each entry names a wound, its root cause, and the rule that now prevents it.

Entries use titles, never ordinal numbers - unnumbered entries reorder freely.

The appendix indexes rules that live in the owning document's body - it does not hold rules.

If no existing rule covers a lesson, add the rule to the owning document first, then index it here.

### Paraphrased review requests resolve to standby

Observed symptom: a request phrased as "autonomous self improvement routine" ran the session review on an implied trigger instead of holding for the recorded phrase - the user then corrected that the agent should have asked for `improve dosound-tracker`.

Root cause: the Trigger section covered only "never implied" for ordinary task requests - it did not state the positive resolution for a request that clearly wants the review but misses the recorded phrase.

Preventing rule: see "Trigger" in `WORKFLOW.md`.
