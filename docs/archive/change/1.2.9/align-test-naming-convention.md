# Align test naming and the declared convention

**Type:** Chore

**Source:** AUDIT-1.2 REC-015 / FND-STR-001

## Summary

The standard declares `PascalCase.test.ts` while all test files are camelCase and `GUIDELINES.md` requires camelCase for non-component TypeScript.

## Description

Resolve the two-document conflict: amend the standard to the camelCase convention the tree actually follows, or rename files to PascalCase. One convention must win in both documents.

## Out of Scope

Renames follow the adopted convention - do not rename twice.
